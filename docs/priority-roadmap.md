# 十二项优先任务进度

这份清单对应用户确认的十二项任务。代码已实现、真实 Excel 验收和任务成功率改善分别记录；不以测试数量证明任务正确性。本轮代码测试 135/135 通过，尚未运行新的真实 Excel 任务评测。

| 优先级 | 能力 | 当前状态 | 剩余工作 |
| --- | --- | --- | --- |
| P0 | 任务语义验证 | 已实现声明式约束检查：原始来源快照、写后检查、正常结束自动重查，以及未检查/失败/不完整的报告 | 用真实 Excel 任务验收；条件由模型根据用户要求声明，不能把条件通过说成完整意图已证明 |
| P0 | 工作簿统一协调与 revision | 同一窗格内的 Office.js 写入及恢复已排队并返回 revision | Office.js、COM 和跨窗格写入尚未共同协调；revision 不覆盖手动修改 |
| P1 | 多会话与历史对话 | 已有按工作簿隔离的历史列表、查看、续接、删除 | 没有并行会话标签；新界面待真实 Excel 操作验收 |
| P1 | 长对话压缩和溢出恢复 | 已接入 SDK 压缩事件展示，工具各自限制输出 | 尚无项目级预算、统一旧结果压缩及溢出后重试 |
| P1 | 操作队列 | 已支持执行期间排队、移除后续指令，并保存提交时选区 | 待真实 Excel 交互验收 |
| P1 | 恢复点管理界面 | 已有列表、关键词筛选、删除、清空和恢复 | 待真实 Excel 交互验收；不代表所有操作均有恢复点 |
| P1 | 工具结果与可视化 diff | 已展示写入回执、范围、状态、公式错误、revision、恢复入口 | 尚无修改前后的可视化 diff；COM 结果未统一展示 |
| P1 | 恢复覆盖 | 已覆盖单元格值/公式、部分格式、排序、清空、尺寸及部分行列/工作表结构修改 | 表格、筛选、图表、透视表、批注、复制表、隐藏/冻结和 COM 仍不完整；跨表引用恢复也有限制 |
| P2 | Provider 与模型管理界面 | 已展示 Provider 和三档模型映射 | 更换 Provider 仍要编辑配置，无完整连接管理界面 |
| P2 | 用量与费用展示 | 已显示最近一轮主代理 Token 用量 | 尚无费用、累计用量及上下文预算展示 |
| P2 | 会话配置兼容性 | 已保存配置指纹，不兼容历史只读 | 尚未覆盖提示词、技能文件内容等全部配置变化，也未完成所有真实 SDK 变更场景验收 |
| P2 | 会话导出、导入和分享 | 未实现 | 产品入口和可迁移格式 |

当前顺序：先验收结果检查，再统一实际会竞争的工作簿操作；随后补长上下文、结果 diff 和恢复覆盖，最后处理配置及记录迁移。单元格 AI 函数、任意 Office.js 执行等属于另一组候选能力，不替代这十二项清单。

任务结果检查的实现依据、复用和范围见 [task-verification-design.md](task-verification-design.md)。
