# 十二项优先任务进度

这份清单对应用户确认的十二项任务。代码已实现、真实 Excel 验收和任务成功率改善分别记录；不以测试数量证明任务正确性。

**2026-09-20 真实 Excel 验收（acceptance/acceptance.xlsx）**：界面五项（空状态引导、运行计时与 Esc 中断、地址点击跳转、读取结果表格、工具卡分组折叠）全部通过；表格创建、工作表筛选、隐藏行列、冻结窗格、图表创建、单元格批注六条恢复路径均生成恢复点，且在面板里恢复后效果正确；写前公式校验拦下了缺右括号的公式（未到 Excel）；Excel 拒绝缺参数公式时保留其原始报错且模型未重发。同日修掉验收中暴露的两个问题：选中图表时元数据读取崩溃、面板恢复导致的 STALE 提示不说明原因。仍未验收：多窗格/COM 交错写入、长对话压缩、会话导入导出与 Provider 切换界面。

同日 10 题评测（sample10-flash-r5，flash 档）：工具报错 62→78→24，平均工具调用 24.4→20.3→17，通过率 4/5/3——通过率在噪声带内，不作为改善证据。
